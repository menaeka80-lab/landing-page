# Landing Page XII TKJ 1

Landing page untuk **Kelas XII TKJ 1** — program keahlian Teknik Komputer dan Jaringan. Halaman profil kelas yang menampilkan tentang kelas, kompetensi keahlian, anggota, jadwal, dan kontak.

## ✨ Fitur

- 🎨 Desain modern dengan animasi partikel di hero
- 📱 Responsif — ramah di HP maupun desktop
- 👥 Daftar anggota interaktif (tambah / ubah nama via klik)
- 🗓️ Jadwal kelas
- 📬 Form kontak
- 🌐 Berbahasa Indonesia

## 🧱 Teknologi

- HTML5
- CSS3 (vanilla)
- JavaScript (vanilla, tanpa framework)

## 📁 Struktur

```
landing page/
├── index.html        # Halaman utama
├── css/
│   └── style.css     # Styling
├── js/
│   └── main.js       # Interaksi & data (anggota, jadwal)
└── README.md
```

## 🚀 Menjalankan Lokal

Buka `index.html` langsung di browser, atau jalankan server lokal:

```bash
# Python
python -m http.server 8000

# Node
npx serve
```

Lalu buka `http://localhost:8000`.
